Shortcuts 

    

      
dbl-click canvas
new node

      
dbl-click node, line, group
edit its label or title (hold a group to rename it too)

      
drag ● handle
connect (drop on empty space = new node)

      
⌥ drag node
connect from node

      
Tab
add connected node (also while typing a label)

      
Enter / F2
edit label · ⇧Enter new line

      
drag into a box
move node into / out of a group

      
⌘G / ⇧⌘G
group / ungroup selection

      
⌘D
duplicate

      
⌘C ⌘V
copy as mermaid · paste mermaid or images

      
⇧ drag
box select

      
⌘ click
follow a node's link

      
scroll / space drag
pan · ⌘/pinch to zoom · 0 fit

      
arrows
nudge (⇧ ×5)

      
⌘Z ⇧⌘Z
undo / redo

      
⌘S
save now

      
⌘P
switch file

      
⌘\ / ⌥⌘\
show / hide the outline, the inspector and code

    

    
Positions are stored in a %% mermdraw:layout comment inside the block. Mermaid ignores it, so GitHub still renders its own automatic layout.

  





  

    
Labs · feature flags 

    
Experiments ship behind flags so they can be tried and iterated on. Your toggles apply to this browser; teams can set defaults in .mermdraw/config.json ({"flags": {"themes": true}}) or with mermdraw --enable themes.
